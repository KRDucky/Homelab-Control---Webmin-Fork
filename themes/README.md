# Theme packs (placeholder — M3)
Themes are declarative token sets (`.hltheme`), never executable code. The M0 UI consumes
`frontend/design-system/tokens.css` (dark default + light via `prefers-color-scheme`); OLED and compact
packs arrive with the theme loader in M3.
